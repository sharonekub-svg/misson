# סוכן טלפוני בעברית — דמו לשמוע

מתקשרים למספר → סוכן AI עונה בעברית כפקיד/ה של מוסך, מנהל שיחה אנושית וקובע תור.

כל מה שצריך כדי לשמוע את זה בטלפון שלך:

## מה צריך (חד-פעמי)

1. **מפתח OpenAI** — נכנסים ל-platform.openai.com → API keys → יוצרים מפתח.
2. **מספר טלפון ב-Twilio** — נרשמים ב-twilio.com (יש קרדיט חינם להתחלה), קונים מספר.
3. **ngrok** — כדי לחשוף את השרת שרץ אצלך לאינטרנט: ngrok.com (חינם).

## הרצה (5 דקות)

```bash
cd voice-agent
npm install

# הגדרות
cp .env.example .env
# פותחים את .env ומדביקים את ה-OPENAI_API_KEY

# מריצים את השרת
npm start
```

בחלון טרמינל שני:

```bash
ngrok http 5050
```

ngrok ייתן כתובת כמו `https://abcd-1234.ngrok-free.app`.
מעתיקים את החלק בלי ה-https:// לתוך `PUBLIC_HOST` בקובץ `.env`, ומריצים מחדש `npm start`.

## חיבור למספר ב-Twilio

בלוח הבקרה של Twilio → המספר שקנית → בשדה
**"A call comes in"** → Webhook →
מדביקים: `https://<הכתובת-של-ngrok>/incoming` ושומרים.

## לשמוע

מחייגים למספר ה-Twilio. רונית עונה בעברית. דברו איתה, נסו לקבוע תור.
