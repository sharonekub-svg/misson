# Up Mission 🎯

A daily-quest dueling app. Every day you get one quest, film yourself doing it,
keep your streak alive, open a chest for coins, and grow your mob.

**Stack:** Flutter (app) + Supabase (accounts, data, video storage, AI quest
checking via a Claude-vision Edge Function).

## What's in here

| Screen | What it does |
|---|---|
| **Quest** (home) | The winding Duolingo-style tile path, your mob bobbing on today's tile, the **DUELING GO** button. The path is built from your real completed quests. |
| **Quest detail** | Today's quest (generated by the server), difficulty, how it's verified. **Film or upload** a video → it's stored in Supabase → AI checks it → quest completes. |
| **Chest** | Reveals the **Rare / Mega / Ultra** roll + coins (rolled server-side). |
| **Shop** | Buy & equip mobs and designs. Purchases spend real coins and persist. |
| **League** | Friends leaderboard ranked by streak (live from the DB). |
| **Friends** | Add friends by username, accept requests, see friend activity. |
| **You** | Your mob, streak, coins, and monthly freezes. |

### The rules it models
- **Weekly difficulty rhythm:** Sun/Mon/Tue = easy · Wed/Thu = medium · Fri/Sat = hard.
- **Streaks** (consecutive days) with **3 freezes per month**.
- **Chests** roll a rarity that multiplies coins; hard quests roll better odds.
- **Verification:** simple quests → **AI** (Claude vision on a video frame);
  hard action quests → a **friend** confirms.

## Run it on your phone / simulator

Install Flutter once: https://docs.flutter.dev/get-started/install

```bash
bash setup.sh     # one-time: generate native folders + fetch packages
flutter run       # plug in your phone, or start a simulator
```

Edit any file and save → it hot-reloads on your phone in ~1 second.

### Two one-time backend toggles
The backend (Supabase project **up-mission**) is already created and connected
(see `lib/data/supabase_config.dart`). Two quick switches in the
[Supabase dashboard](https://supabase.com/dashboard):

1. **Enable anonymous sign-in** (required): Authentication → Providers →
   **Anonymous** → enable. The app signs each player in anonymously on first
   launch. (If this is off you'll see a "Couldn't connect" screen.)
2. **Enable real AI checking** (optional): Project Settings → Edge Functions →
   Secrets → add `ANTHROPIC_API_KEY`. Without it, the verifier runs in
   **demo mode** and approves every video so you can test the full loop.

### Phone permissions for the camera
`flutter create` sets up the basics; for recording/uploading add:
- **iOS** (`ios/Runner/Info.plist`): `NSCameraUsageDescription`,
  `NSMicrophoneUsageDescription`, `NSPhotoLibraryUsageDescription`.
- **Android**: the system picker handles permissions automatically.

### Show friends a test build (before the store)
- **Android:** `flutter build apk` (share the file) or Play "internal testing".
- **iPhone:** TestFlight.

```
  schema.sql              full database schema, RLS, functions, storage
  seed.sql                the quest pool
  functions/verify-quest/ the Claude-vision Edge Function
```

## How the daily loop works
1. App signs in anonymously → a `profiles` row is auto-created.
2. `ensure_today_quest()` generates today's quest from the pool by weekday.
3. You film/upload → video goes to the private `quest-videos` bucket.
4. AI quests: a frame is sent to the `verify-quest` function (Claude vision).
5. `complete_quest()` rolls the chest, banks coins, bumps the streak, and
   notifies your friends — all server-side, enforced by Row Level Security.
